# Gift Radar — парсер маркета подарков Telegram

Программа следит за резейл-маркетом коллекционных подарков Telegram и показывает
живой лентой каждый новый выставленный лот: название, номер, цену, модель,
фон, символ и редкость. Кнопка **✓ Готово** на карточке убирает лот из ленты
(карточка плавно схлопывается).

Готовый файл: `dist\GiftRadar.exe` — 56 МБ, ничего доустанавливать не нужно.

---

## 1. Что нужно перед первым запуском

Программа работает через официальный Telegram API от имени вашего аккаунта,
поэтому нужны личные ключи приложения:

1. Откройте <https://my.telegram.org> и войдите по номеру телефона.
2. Раздел **API development tools** → создайте приложение
   (App title и Short name — любые, например `giftradar`).
3. Скопируйте **api_id** (число) и **api_hash** (32 символа).

Ключи спрашиваются один раз и сохраняются локально.

## 2. Первый запуск

1. Запустите `dist\GiftRadar.exe`.
2. Вставьте `api_id` и `api_hash` → **Сохранить**.
3. Введите номер телефона в международном формате: `+79000000000`.
4. Введите код, который придёт в Telegram.
5. Если включена двухфакторная защита — введите облачный пароль.

После входа слева появится «● Ваше имя» и подтянется список коллекций.
Сессия сохраняется: следующие запуски входа не потребуют.

## 2.1. Демо-режим (без ключей)

Если ключей ещё нет или my.telegram.org упорно отдаёт `ERROR`, интерфейс можно
посмотреть вживую: в окне ввода ключей нажмите **Посмотреть демо**. Лента
начнёт наполняться придуманными лотами, работают фильтры, кнопки и анимации.
Telegram при этом не используется вообще, настройки на диск не пишутся.

Если ключи уже сохранены, демо открывается флагом:

```bash
GiftRadar.exe --demo
```

## 3. Как пользоваться

1. В списке **КОЛЛЕКЦИИ** отметьте те, что нужно отслеживать
   (в скобках — сколько лотов сейчас на резейле). Кнопки «Все» / «Снять» /
   «Обновить» ускоряют выбор.
2. Нажмите **▶ Запустить**.
3. Первый круг проходит молча — программа запоминает текущее состояние рынка.
   Дальше в ленту падают **только новые** лоты, по мере появления.
4. Разобрались с лотом — нажмите **✓ Готово**, карточка исчезнет.
   **Открыть** ведёт на страницу подарка `t.me/nft/...`.

Хотите увидеть и уже висящие лоты — включите «Показать лоты, что уже висят»
до запуска (лента заполнится сразу сотнями карточек).

## 4. Настройки в сайдбаре

| Параметр | Что делает |
|---|---|
| Круг опроса | пауза между полными обходами выбранных коллекций |
| Между запросами | пауза между отдельными запросами к API |
| Лотов за запрос | сколько свежих лотов проверять в каждой коллекции (10–100) |
| Цена от / до, ⭐ | фильтр по цене; 0 — без ограничения; к TON-лотам не применяется |
| Валюта лота: ⭐ / TON | какие лоты показывать. Снять обе нельзя |
| Только коллекции с резейлом | прячет коллекции, где сейчас никто ничего не продаёт |
| Показать лоты, что уже висят | выдать текущий рынок при старте, а не только новинки |
| Подарков не больше | пропускать лот, если у продавца больше N обычных подарков; 0 — не проверять |
| NFT не больше | то же для уникальных подарков |
| Только те, кому можно написать | скрывать продавцов с закрытыми ЛС, платными сообщениями и скрытым профилем |
| Только русскоязычные продавцы | по стране номера, языку клиента и кириллице в профиле |
| Прятать лоты со скрытым продавцом | по умолчанию выключено: такие лоты показываются |
| Звук при новом лоте | системный сигнал, не чаще раза в 2 секунды |

Настройки сохраняются при закрытии окна.

**Про валюты.** Продавец выставляет подарок либо за звёзды, либо за TON —
других вариантов Telegram в API не отдаёт. Галочки «⭐» и «TON» переключаются
на лету, прямо во время сканирования, перезапуск не нужен. Пороги «Цена от/до»
заданы в звёздах, поэтому TON-лоты они не отсеивают: если нужны только дорогие
TON-лоты, снимите галочку «⭐» и ориентируйтесь по ленте.

**Про скорость.** Один круг = один запрос на коллекцию. При 30 коллекциях и
задержке 0.6 сек круг занимает ~20 сек, то есть лот попадает в ленту в среднем
за 20–40 секунд после выставления. Ставить задержку ниже 0.4 сек не стоит:
Telegram ответит `FLOOD_WAIT` и парсинг встанет на минуты. Программа такие
паузы переживает сама — пишет в статус и ждёт, — но чем агрессивнее опрос,
тем чаще это происходит.


## 5. Фильтр по владельцу

Три настройки отсекают лоты по продавцу — они есть и в окне (раздел
«ВЛАДЕЛЕЦ ЛОТА»), и в боте (кнопка **👤 Владелец**):

* **Подарков не больше N** — сколько у продавца обычных подарков в профиле;
* **NFT не больше N** — сколько уникальных (апгрейженных) подарков;
* **Только те, кому можно написать**;
* **Только русскоязычные продавцы**.

Как считается. Число подарков берётся из профиля продавца
(`UserFull.stargifts_count`), уникальные отделяются запросом
`getSavedStarGifts(exclude_unique=True)`: что не обычное — то NFT. Считаются
только подарки, **видимые в профиле**: спрятанные владельцем Telegram не отдаёт
никому, так что тихого коллекционера с закрытой витриной фильтр посчитает пустым.

Можно ли написать — определяется по профилю: закрытые ЛС
(`contact_require_premium`, если у вас нет Premium), включённые платные
сообщения, удалённый аккаунт или бот. Стопроцентной гарантии тут нет: Telegram
не отдаёт полные настройки приватности чужого аккаунта, окончательно это
выясняется только при отправке. Зато очевидные «глухие» случаи отсеиваются, и
ссылка на такой лот не придёт.

Русскоязычность определяется по совокупности признаков: страна номера
(RU, BY, KZ, KG, UA), язык клиента и кириллица в имени или в описании профиля.
Точного поля «язык собеседника» Telegram не отдаёт, поэтому это тоже эвристика:
русский с американским номером и латинским ником может не пройти, а иностранец
с кириллицей в био — пройти.

**Скрытые продавцы.** У изрядной части лотов Telegram вообще не показывает
владельца — проверить его нечем. Такие лоты фильтр **пропускает** (иначе он
выкашивал бы почти весь маркет). Если они не нужны — включите «Прятать лоты со
скрытым продавцом» в окне или «прятать скрытых» в боте.

Панель бота показывает, из-за чего именно лоты не дошли: «продавец скрыт»,
«много подарков», «нельзя писать», «не русскоязычный», «цена/валюта». По этой
строке сразу видно, какую настройку ослабить.

**Повторы.** Показанные лоты запоминаются в `seen.json` рядом с настройками,
поэтому после перезапуска бот не присылает то же самое заново. Хранится до
200 000 ключей за последние 30 дней; кнопка **🧹 Забыть виденное** очищает файл.
Если память не пуста, молчаливый первый круг не нужен — новые лоты пойдут сразу.

**Картинка.** В сообщении о лоте спрятана ссылка на страницу подарка, поэтому
Telegram сам подтягивает превью — изображение самого NFT.

**Цена вопроса — запросы.** Каждый новый продавец стоит 2 дополнительных
обращения к API. Результат кэшируется на 30 минут (один продавец обычно
выставляет несколько лотов подряд), но при широком захвате коллекций фильтры
заметно повышают шанс поймать `FLOOD_WAIT`. Если это началось — поднимите
«между запросами» до 1.0 сек или сократите список коллекций. Кнопка
**🧹 Забыть виденное** в боте заодно сбрасывает и кэш владельцев.

## 6. Где лежат данные

Запущенный `.exe` хранит файлы в `%APPDATA%\TgGiftRadar`:

* `config.json` — настройки и ключи API;
* `session.session` — авторизация Telegram.

Запуск из исходников кладёт то же самое в папку `data\` рядом с проектом.
Кнопка **Выйти из аккаунта** отвязывает сессию и удаляет её файл.
Если что-то сломалось — закройте программу и удалите папку `%APPDATA%\TgGiftRadar`.

## 7. Запуск из исходников и пересборка

```bash
python -m pip install -r requirements.txt
```

```bash
python run.py
```

Пересобрать exe:

```bash
python -m PyInstaller gift_radar.spec --noconfirm --clean
```

Или просто двойным кликом по `build.bat`.

Сборка идёт в один файл (`onefile`), из-за чего exe стартует 3–5 секунд —
распаковывается во временную папку. Если нужен мгновенный старт, замените в
`gift_radar.spec` блок `EXE(...)` на связку `EXE`+`COLLECT` (режим `onedir`):
получится папка `dist\GiftRadar\` с exe и библиотеками рядом.

## 8. Структура кода

```
run.py                 точка входа, тема, диалог ключей
app/config.py          настройки и пути (%APPDATA% в exe, data/ в исходниках)
app/core/models.py     разбор TL-объектов Telegram в структуру Listing
app/core/demo.py       генератор фейковых лотов для демо-режима
app/core/scanner.py    запросы к маркету, общие для окна и бота
app/core/owner.py      проверка продавца: подарки, NFT, можно ли написать
app/core/bot_runner.py телеграм-бот: аккаунт читает, бот рассылает
app/core/bot_ui.py     клавиатуры и экраны меню бота
bot.py                 точка входа бота (консоль)
app/core/worker.py     поток с asyncio + Telethon: вход, каталог, цикл опроса
app/ui/theme.py        палитра и таблица стилей Qt
app/ui/widgets.py      карточка лота, аватар-градиент, анимация исчезновения
app/ui/dialogs.py      ввод ключей и шаги авторизации
app/ui/main_window.py  сайдбар, лента, вся логика окна
gift_radar.spec        конфигурация PyInstaller
```

Как это устроено: воркер зовёт `payments.getResaleStarGifts` по каждой
выбранной коллекции без флагов сортировки — Telegram отдаёт лоты в порядке
выставления, свежие первыми. Пары `(id коллекции, номер подарка)` копятся в
множестве `_seen`; всё, чего там ещё нет, считается новым лотом и уходит в
интерфейс сигналом `found`. Сеть живёт в отдельном потоке со своей asyncio-петлёй,
поэтому окно не подвисает даже во время `FLOOD_WAIT`.

## 9. Телеграм-бот вместо окна

`dist\GiftRadarBot.exe` — та же слежка, но лоты приходят сообщениями в Telegram.

**Почему нужен и аккаунт, и бот.** Метод `payments.getResaleStarGifts` доступен
только пользовательскому аккаунту — боты витрину маркета не видят вообще.
Поэтому в одном процессе живут два клиента: ваш аккаунт читает маркет, а бот
рассылает найденное. Токен бота нужен, чтобы сообщения приходили от него,
а не от вашего аккаунта.

Настройка:

1. Откройте @BotFather → `/newbot` → имя и username → скопируйте токен
   вида `1234567890:AAH...`.
2. Запустите `dist\GiftRadarBot.exe`. Он спросит токен (и ключи API, если их
   ещё нет в конфиге), затем — телефон и код для входа в аккаунт.
3. Напишите своему боту `/start` — с этого момента лоты идут в чат.

У бота своя сессия аккаунта (`session_bot_user`), отдельная от десктопной,
поэтому код при первом запуске придётся ввести ещё раз. Зато окно и бота
можно держать запущенными одновременно.

Всё управление — прямо в чате, окно для этого не нужно.

| Команда | Что делает |
|---|---|
| `/menu` | панель управления кнопками — главный экран |
| `/start` | подписаться на новые лоты |
| `/stop` | отписаться |
| `/status` | коротко: слежение, коллекции, подписчики |
| `/find pepe` | поиск по коллекциям; `/find` без слова сбрасывает |
| `/set круг 30` | точное значение параметра |
| `/help` | справка |
| `/setup_group` | привязать текущую супергруппу и попытаться найти её топики |
| `/bind <ключ>` | вручную привязать текущий топик к категории |

Команде `/set` доступны: `круг` (сек), `пауза` (сек между запросами),
`лимит` (лотов за запрос), `от` и `до` (цена в звёздах), `подарки` и `нфт`
(лимиты по владельцу).

**Панель `/menu`** — живой HUD: бот держит одно сообщение, закрепляет его в чате
и обновляет сам — каждые 10 секунд, даже когда сканирование стоит на паузе
(во время круга чаще, но не чаще раза в 5 секунд, чтобы не спамить). В ней
видно полоску прогресса текущего круга с названием коллекции, время работы,
сколько лотов найдено и отправлено, сколько отсеяно фильтрами и владельцем,
когда был последний лот, и вся текущая конфигурация одной сводкой.

Под полем ввода появляется постоянная клавиатура: **▶️/⏸**, **📊 Панель**,
**🎁 Коллекции**, **⚙️ Параметры**, **👤 Владелец** — в меню можно не лазить.

Разделы панели:

* **⏸ Пауза / ▶️ Запустить** — слежение останавливается и продолжается на лету;
* **🎁 Коллекции** — список с галочками по 8 на страницу, стрелки `‹ ›`,
  кнопки «Все с резейлом» и «Снять все». Поиск — командой `/find`;
* **⚙️ Параметры** — круг опроса, пауза, лимит кнопками ±, переключатель
  «показывать лоты, которые уже висят» и **🧹 Забыть виденное** (сбрасывает
  память, чтобы рынок пересобрался заново);
* **👤 Владелец** — лимиты «подарков ≤ N» и «NFT ≤ N» кнопками ±, переключатель
  «только те, кому можно написать», кнопка сброса лимитов;
* **⭐ / TON** — переключатели валют прямо на главном экране; снять обе бот не даст.

Любая настройка применяется со следующего круга и сохраняется в `config.json` —
перезапуск её не потеряет. Настройки общие с десктопной версией: что выбрано
кнопками в боте, то увидит и окно.

В сообщении о лоте видно продавца: юзернейм ссылкой (`@name`) и имя рядом.
Если юзернейма нет — так и написано, «без юзернейма»; если владелец скрыт —
«продавец скрыт».

Кнопки под лотом: **Открыть** (страница подарка), **Написать** (чат с продавцом,
появляется только когда юзернейм известен) и **✓ Готово** — она удаляет сообщение
из чата, ровно как карточка исчезает в окне. Те же кнопки есть и в карточке окна.

За один круг в чат уходит не больше 200 лотов, остальное сворачивается в строку
«…и ещё N» — иначе при широком захвате Telegram упрётся в лимиты бота.

### Привязка группы и топиков

1. Создайте супергруппу с темами форума и добавьте бота администратором.
2. После перезапуска бот сам подключит единственную найденную форумную группу
   и попробует сопоставить существующие темы с категориями по названиям
   (`300-1000`, `черный фон`, `Khabib's Papakha` и т. п.). Если групп несколько
   или автоопределение не сработало, в самой нужной группе отправьте
   `/setup_group`.
3. Если какая-то тема не нашлась автоматически, отправьте в ней
   `/bind <ключ>`. Ключи категорий бот покажет в ответе на `/setup_group`.

Лот отправляется только в одну тему. Сначала проверяются специальные категории
(Khabib, UFC, чёрный фон, язык/страна и т. п.), затем дорогие модели и только
после этого — ценовой диапазон. Если приоритетная категория выключена или её
топик не привязан, выбирается следующая доступная категория.

В группе у карточки есть кнопка `! WORK`. Первый нажавший забирает лот:
сообщение удаляется из группы, а карточка отправляется победителю в личные
сообщения. Автоматической рассылки каждого лота всем подписчикам нет.

Пересобрать бота:

```bash
python -m PyInstaller gift_radar_bot.spec --noconfirm --clean
```

## 10. О чём стоит знать

* Программа работает как обычный пользовательский клиент (userbot). Это
  допустимо, но Telegram не любит агрессивный опрос: слишком короткие паузы
  ведут сначала к `FLOOD_WAIT`, а при упорстве — к ограничениям на аккаунт.
  Разумно держать «между запросами» ≥ 0.5 сек и не отмечать все коллекции разом.
* Ключи и сессия — это полный доступ к вашему аккаунту. Не передавайте
  `config.json` и `.session` третьим лицам и не выкладывайте их в общий доступ.
* Программа только читает витрину и ничего не покупает.
